# Jihan Private Room

เว็บแชตโรลเพลย์กับ "กง จื่อหาน" แบบตอบสดด้วย OpenAI Responses API

## เอาไปทำเป็นลิงก์สาธารณะ
1. สมัคร/ล็อกอิน Vercel
2. Import โปรเจกต์นี้
3. ตั้ง Environment Variable ชื่อ `OPENAI_API_KEY` เป็น API key ของคุณ
4. Deploy แล้วเปิด URL ที่ Vercel ให้

**อย่าใส่ API key ลงใน `index.html`** เพราะคนอื่นจะเห็นได้
